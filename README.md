## 暗号化ゲートジェネレーター

ブログ記事の一部を、パスワードを知っている人だけが読めるようにするためのツールです。
本文をブラウザ内でAES-256-GCM暗号化し、貼り付け用のHTMLコードを生成します。

**パスワードやハッシュはコードに含まれません。** 公開されるのは暗号文だけです。

### 使い方

1. `index.html` を開く (GitHub Pagesで公開するとそのまま使えます)
2. タイトル・テーマ (ライト/ダーク)・パスワード・隠したい本文 (HTML) を入力して「暗号化して生成」(生成後にテーマを切り替えると、再入力なしでゲートの見た目だけ更新されます)
3. 生成されたコードをブログのHTML編集モードに貼り付ける

入力内容は外部に送信されません。

### 仕組み

- 暗号: AES-256-GCM
- 鍵導出: PBKDF2 (SHA-256、600,000回、ランダムソルト)
- 復号はWeb Crypto APIを使うため、HTTPS環境が必要です

### 注意

- 暗号文は誰でも入手できるため、オフライン総当たりは防げません。**強いパスワードが前提です。**
- 復号後の本文内の `<script>` は実行されません。
- 画像ファイル自体が公開されていれば、URLを知る人は閲覧できます。
- 外部サーバーでの認証ではないため、高い機密性が必要な用途には向きません。
